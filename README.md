# CodeGuard AI — Intelligent Developer Code Review & Engineering Intelligence Platform

CodeGuard AI is an intelligent developer productivity and automated code-review platform. It analyzes source code to identify bugs, security vulnerabilities, performance issues, code smells, maintainability issues, and architecture problems.

## Tech Stack
- **Backend**: Java 21, Spring Boot 3
- **Developer Portal**: React, TypeScript, Vite
- **Admin Portal**: Angular, TypeScript
- **Services**: Node.js, Flask, FastAPI (Python AI), C# Roslyn Analyzer
- **Databases & Messaging**: PostgreSQL, Redis, Apache Kafka
- **Infrastructure**: Docker, Docker Compose

## Phase 1 Structure
In Phase 1, we establish the foundation:
- Root repository configurations
- PostgreSQL database integration
- Initial Spring Boot core backend with a health check
- Initial React developer portal
- Initial Angular admin portal
- Docker Compose configuration orchestrating the services
